## 🛠️ MCP Tools Exposed
- `prescribe_percussion_therapy_protocol`: Recommend percussion massage gun amplitude (mm), frequency (RPM/Hz), and head attachment for muscle group.
- `calculate_ischemic_compression_countdown`: Calculate optimal static compression pressure duration to release taut hyperirritable muscle bands.
